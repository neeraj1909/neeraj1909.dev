01 FRAMEWORK / LEXSI AI

DLBacktrace

Deep models span many architectures and tasks, which makes relevance tracing difficult to inspect consistently. DLBacktrace is a model-agnostic explainability framework for transformers, language models, and Mixture-of-Experts architectures.

MY WORK

During my Research Scientist role at Lexsi AI (April 2024–March 2026), my resume describes building graph tracing, activation capture, relevance propagation, evaluation, compressed trace storage, and visualization pipelines. It also describes expanding LLaMA-family and MoE support.

EVIDENCE

The public framework README describes architecture and task support. My resume lists SHAP, LIME, and Integrated Gradients comparisons; no independent benchmark result is asserted here.

Indic Research Agent

India- and Indic-language research questions can require searching several public sources and carefully synthesizing what they support. This assistant exposes the search and synthesis workflow through a Chainlit interface.

MY WORK

I built a LangGraph workflow with a typed public-search tool backed by query-kit, direct OpenAI synthesis, streamed progress, PostgreSQL history, and Redis caching.

EVIDENCE

The project README describes the query → search → source-backed synthesis flow. Its current boundary is public-provider search; it does not search a local document corpus.

query-kit

Research-source searches often return provider-specific results that are awkward to reuse. query-kit is a small Python CLI and library that normalizes public search results and removes duplicates.

MY WORK

I built the provider adapters and a shared interface with normalized text/JSON output and synchronous and asynchronous APIs.

EVIDENCE

The README documents public providers including ACL Anthology, arXiv, PubMed, Semantic Scholar, and OpenReview. It describes local installation; it does not claim a PyPI release.

Explainable Agentic RAG

Comparing document-grounded RAG workflows means making retrieved evidence and orchestration choices inspectable. This local LangGraph prototype includes baseline and agentic paths, source attribution, and a comparative evaluation harness.

MY WORK

I implemented retrieval and retry workflows, typed request/response contracts, attribution, tracing, and evaluation tooling across four local-PDF modes.

EVIDENCE & LIMITS

The repository includes ten curated evaluation questions and a runner, but no generated metric report. Retrieval is dense-only, verification uses token overlap rather than NLI, and durable human-review resumption is incomplete.
